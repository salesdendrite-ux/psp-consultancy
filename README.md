# PSP Consultancy — Website

Static site for PSP Consultancy (business & financial advisory), affiliated with PSP & Associates (Chartered Accountancy firm).

## Structure
- `index.html` — homepage
- `insights.html` — Insights listing page
- `styles.css` — shared stylesheet
- `images/` — client logo source files (not required for the deployed site; logos are embedded as base64 in index.html)
- `robots.txt`, `sitemap.xml`, `llms.txt` — crawler/SEO/AI-visibility files (update the placeholder domain once the real one is live)

## Deploy
This is a static site with no build step. Deploy as-is to Vercel, Netlify, or any static host.
